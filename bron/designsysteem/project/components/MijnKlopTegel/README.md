# MijnKlopTegel

Actietegel in Mijn Klop (Serviceplanner, Afspraken, Seizoenschecklist, Logboek, Documenten, Klop Premium Service™). Wit vlak, `radius-kader` 14px, titel in Funnel Display 300, korte regel in Staal en onderaan "Open" met een gele hairline. De tegels voor Klop Premium Service™ zijn informatief ("Onderdeel van je pakket") en niet klikbaar. Menu links: Nachtblauw, actief item met gele markering, teller als gele pill. Op mobiel een horizontale tabbalk.
