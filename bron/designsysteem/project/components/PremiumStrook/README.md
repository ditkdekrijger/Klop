# Premium Service-strook

Volle gele band op de home, één keer per pagina. Een bewegende band met de vier onderdelen bovenin, de nachtblauwe pil Klop Premium Service™ (klikbaar), de kop "Wij regelen het gedoe. U vaart.", een foto met waterlijst-kader, de persoonskaart van het vaste aanspreekpunt (foto, naam, bellen, WhatsApp) en vier fototegels: Onderhoud (werkplaats), Schoonmaak (stuurwiel), Stalling (steiger), Halen en brengen (trailer). Daaronder de drie stappen, klein. Onderaan een Vaarspoor in nachtblauw. Op hover: foto zoomt, kader sluit, icoonring wordt geel, golflijn loopt.
