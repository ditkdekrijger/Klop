# MerkHero

Opening van een merkpagina: grote foto met het logo op een witte plaat, merkverhaal in een korte alinea, daarna type-tegels, uitgelichte boten in afwisselende rijen, galerij van 8 (of 4) foto's en een slotbanner. Knoptekst: "Bekijk alle n boten van <merk>"; bij één boot "Bekijk de boot van <merk>". Maxima Boats krijgt geen Klop-opmaak.
