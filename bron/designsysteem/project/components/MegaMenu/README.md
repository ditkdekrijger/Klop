# MegaMenu

Uitklapmenu onder Boten, Showroom, Klop Premium Service en Over ons. Volgorde van de hoofdnavigatie: Boten, Showroom, Klop Premium Service, Over ons. Onder Boten staan merken met logo op een witte plaat en soorten boten met foto, geen losse tekstlijst. Tegels hebben `radius-water`. Alleen zichtbaar vanaf 1180px; daaronder werkt het mobiele menu.
