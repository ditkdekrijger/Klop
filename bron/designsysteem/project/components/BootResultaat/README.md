# Bootresultaat (lijstkaart)

Booking-stijl resultaatkaart: foto links met label (Laagste prijs, Langste boot, Gunstigste prijs per meter, alleen berekend uit echte data), midden specificaties met iconen, rechts prijs, prijs per meter, indicatieve maandlast met voetnoot, Bekijk boot en Vergelijk. Filters hebben live aantallen, actieve filters zijn chips, sorteren is een rij pillen. Geen verzonnen urgentie of reviews.
