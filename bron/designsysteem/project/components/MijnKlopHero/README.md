# MijnKlopHero

Opening van Mijn Klop: Nachtblauw vlak (radius 22px) met begroeting in weight 300, korte alinea en twee pillen (Plan service geel, Maak afspraak omlijnd), rechts een foto van de eigen boot. Eronder drie cijfertegels (volgende afspraak, voortgang checklist, serviceverzoeken). In de demo-omgeving staan alleen voorbeeldgegevens, nooit verzonnen cijfers.
