# Iconen

26 lijniconen op een raster van 48 x 48. Eén inkt: Nachtblauw `#0B1930` (in de SVG-bestanden vastgelegd, want een afbeelding kan geen `currentColor` erven). Op donkere vlakken gebruikt u de inline versie uit het component Icon, die wit wordt.

- Lijndikte 1.25 px, niet schalend: op elke maat dezelfde hairline als het waterlijst-kader.
- Ronde lijneinden en ronde hoeken, zoals water: geen scherpe punten. Cirkels zijn open.
- Merkdetail: een kleine open cirkel (het oog van het gele label) komt terug in een deel van de iconen.
- Nooit geel. Geel betekent "geregeld" en staat alleen op het label.
- Gebruik 24 px in navigatie, 36 px in tegels, 48 tot 56 px boven een kop.
